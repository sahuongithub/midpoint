# There are none, and that is deliberate.
#
# Every module in tools/ imports only the Python standard library. The statistics
# this project reports -- Student's t, the incomplete beta function, bootstrap
# intervals, Wilson intervals, Spearman and sign tests -- are implemented in
# tools/statlib.py and verified against closed-form values, rather than pulled in
# from SciPy. Market data goes over urllib. There is no dataframe library, no
# model, and no vector store.
#
# This file previously listed streamlit and pandas. Nothing ever imported either;
# they were scaffolding from a shape this project did not end up taking, and a
# dependency you do not use is a claim you cannot support.
#
# To run everything:
#     python3 tools/run_tests.sh      # the full suite, offline
#     python3 tools/agent.py --help   # the trading loop
