# The agent, the risk kernel and every analysis in this repository import only the
# Python standard library. The statistics they report -- Student's t, the incomplete
# beta function, bootstrap and Wilson intervals, Spearman and sign tests -- are
# implemented in tools/statlib.py and checked against closed-form values rather than
# pulled in from SciPy. Market data goes over urllib. There is no dataframe library,
# no model, and no vector store.
#
#     python3 tools/run_tests.sh      # the full suite, offline, no installs
#     python3 tools/agent.py --help   # the trading loop
#
# The two packages below are needed ONLY by app.py, an optional local operator view.
# Nothing else in the repository imports them, and the published application at
# sahuongithub.github.io/midpoint is static HTML that needs neither.
streamlit>=1.38
pandas>=2.0
